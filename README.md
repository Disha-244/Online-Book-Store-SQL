📚 Online Bookstore SQL Data Analysis Project

📌 Project Overview

This project analyzes an online bookstore database using PostgreSQL. It explores books, customers, and orders to answer business questions and demonstrate SQL skills used in Data Analyst roles.

🎯 Project Objectives

- Analyze book inventory, prices, genres, and publication years.
- Explore customer information and ordering patterns.
- Calculate sales and revenue metrics.
- Identify top-selling books and customer purchasing trends.
- Practise SQL queries to solve real-world business problems.

🗂️ Database Tables

The project uses the following tables:

- Books: Book details, authors, genres, prices, publication years, and stock.
- Customers: Customer details and locations.
- Orders: Order dates, book purchases, quantities, and order amounts.

🛠️ Tools & Technologies

- PostgreSQL
- SQL
- pgAdmin
- GitHub

💡 SQL Concepts Used

- SELECT, WHERE, ORDER BY, LIMIT
- Aggregate functions: COUNT, SUM, AVG, MIN, MAX
- GROUP BY and HAVING
- DISTINCT and CASE
- JOINs
- Subqueries
- Advanced SQL queries

📊 Business Questions Explored

1. How many books are available in the bookstore?
2. Which books have the highest prices?
3. Which genres are available?
4. How many books have been sold in each genre?
5. Which customers have placed multiple orders?
6. What is the total revenue generated from orders?
7. Which books have low stock?
8. Which books and customers contribute most to sales?

📁 Project Files

📈 Key Findings

Key business insights will be documented here after executing the analysis queries and verifying the results.

🚀 How to Use This Project

1. Install PostgreSQL and pgAdmin.
2. Create the bookstore database.
3. Create or import the required tables and data.
4. Open "SQL_Queries.sql" in pgAdmin's Query Tool.
5. Execute the queries and review the results.
